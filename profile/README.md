# NCPlot

> NCPlot keeps G-code preview, the toolpath plot, and the posted file check on one shop review so motion stays visible before the machine starts.

## Four Beats

1. **Name the file.** Give the NCPlot session a short title before you open posted G-code.
2. **Pin the live path.** Keep current motion and the toolpath plot on the NCPlot board and leave unused files aside.
3. **Check the plot.** Read the NCPlot summary of the posted file check before you treat motion as final.
4. **Close the loop.** Note which previews are ready so the next NCPlot visit does not start by hunting the G-code.

## First Questions

**Does NCPlot replace the machine start?**  
No. NCPlot sits beside the posted file and the shop traveler you already use.

**Can two operators share one computer?**  
Yes. Each person keeps a separate NCPlot profile.

**Will NCPlot stay workable on an older office laptop?**  
Yes. NCPlot is meant to stay light during a normal shop review.

**What should a new user try first?**  
One small NCPlot G-code preview today, then the same toolpath plot again tomorrow.

## Field Note

NCPlot is easier to trust when the preview stays smaller than the posted file it came from. A named session shows which program is active, the pins show which motion you will read today, and the closing note tells the next person which G-code preview matches the toolpath plot. That record is short on purpose: not a copy of every block, only the path back to the file that is still open.

The same loop fits a student program, a client posted file, or a computer shared by two operators. Open the last NCPlot session, confirm one plot, and leave the shop review easier to follow than you found it. Travelers stay where they are. NCPlot only holds the G-code preview, the summary, and the handoff.

## One Real Pass

Pick a posted file that already has a name: a short contour, a drilled plate, or a simple pocket. Open it in NCPlot, keep only that motion on the board, and read one toolpath plot you can point to. A pass is done when that plot is tied to the posted file check and the unused programs are no longer in the way. NCPlot does not need a full rebuild of the G-code before it is useful.

If the pass feels crowded, the preview is too wide. Drop anything that belongs to a different machine and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first block to the last move, with the summary still matching the toolpath plot on the board.
